RAG 检索链路图
三类知识源 · 离线索引 + 在线检索两条链路 · 设计示意
链路一：离线索引构建与知识更新
场景知识库：场景脚本 / 角色卡 / 常用表达 / 文化背景 学习资源库：语法点 / 词汇表 / 范文 用户个性化库：历史错误 / 偏好话题 / 掌握进度 / 复习状态
知识源结构化定义 + 文档
→
文档切分按语义与长度切块，保留来源元数据
→
向量化Embedding 模型生成向量
→
向量库向量索引 + 关键词索引 + 元数据过滤
更新机制：场景/学习内容经审核后发布上线并重建索引；用户画像在每次会话结束后由 Kafka 异步增量写入（错误点、水平变化、偏好话题）。
链路二：在线检索与生成
查询构造Agent 上下文（当前轮 + 场景目标 + 用户画像摘要）
→
混合召回向量检索 + 关键词检索，按场景限定知识域
→
重排相关性排序，截取 Top-K（按延迟预算控制）
→
注入 Prompt检索片段带引用标记注入，限定只用检索内容作答
→
LLM 生成角色回复 / 反馈建议 / 复盘总结
→
引用溯源生成内容可回查知识来源，降低幻觉
检索延迟预算：对话链路 ≤ 300ms，反馈/复盘 ≤ 1s（目标值，待压测校准） 质量指标：召回相关性、引用忠实度、幻觉率（离线评测集 + 在线抽样） 权限与隔离：用户画像库按用户隔离，跨用户不可检索
对话阶段主要检索场景知识库与用户画像（保证角色一致性与难度适配）；反馈与复盘阶段主要检索学习资源库与用户画像（保证建议有依据、计划有个性化）。三类知识库的切分策略、Embedding 模型与向量库选型在技术方案阶段确定。
