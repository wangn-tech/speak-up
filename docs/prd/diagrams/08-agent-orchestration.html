LangGraph 实现说明：ReAct 用「循环边 + ToolNode」（工具执行节点）表达；DAG 用「并行分支 + 条件边 + 汇合节点（reduce）」表达。两类模式共用同一 StateGraph 基础设施：状态 Schema、超时、幂等、重试与可观测（每步输入输出摘要 / 延迟 / 错误 / token 消耗入日志与 Prometheus 指标）均为图内声明式配置。gRPC 契约：在线 ReAct 会话走 ConversationService（StreamChat 流式）；离线 DAG 任务走 EvaluationService / ReviewService（提交 + 查询，异步回调）。
